How to use the Simulator

  • The machine you saved in the Builder loads here automatically.
  • Type an input string onto the tape and click "Load Input".
  • Use "Step" to run the machine one step at a time, or "Run" to execute it automatically.
  • Watch the current state, head position, and tape update in real time.
  • When the machine halts, you'll see whether the input was accepted or rejected. Click "Reset" to start over.
