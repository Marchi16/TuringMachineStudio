How to use the Builder

  • Click "Add State" to create a new state.
  • Right-click a state to set it as Start, Accept, or Reject.
  • Choose From/To states, fill in Read/Write/Move, then click "Add Transition".
  • Use "Save Machine" to save your work, then "Open Simulator" to run it.
  • Use "Clear" to delete everything and start over.
